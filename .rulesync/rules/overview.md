# Generated repository instructions

`AGENTS.md` and `CLAUDE.md` are generated by RuleSync. Do not edit either file
directly. Edit `.rulesync/rules/*.md`, run `pnpm rules:generate`, and commit the
sources and generated outputs together.

Fina is an early-stage multi-user financial product. Read `PROJECT.md` before a
behavior, security, configuration, or architecture change. It is the source of
truth for current/target/gap status and domain invariants; existing unfinished
code is not automatically the specification.

- Use Node.js 24.21.0 and pnpm 10.0.0 through Corepack. Do not use npm or yarn.
- Workspaces are `apps/api` (NestJS), `apps/web` (React/Vite), and
  `packages/types` (transport-neutral Zod contracts).
- Preserve unrelated working-tree changes. Never discard or overwrite user work.
- A task is complete only when relevant tests and `pnpm verify` pass, generated
  artifacts are current, and behavior/configuration/security documentation is
  updated where applicable.
- TypeORM migrations are the only production schema-change mechanism. Never use
  schema synchronization or undocumented manual production changes.
